# Writing and code cleanup skills

These three skills are unchanged copies from the official Cursor plugins repository, pinned in `WRITING_SOURCE.json`. Each directory retains its original MIT license. Lauren Tan's pstack contains `technical-writing` and `unslop`; Cursor team kit contains `deslop`.

The standard installer could not start in this cloud environment. The inspected Markdown and license files were copied into this project without running upstream code.

Use `technical-writing` and `unslop` for README files, documentation, PR descriptions, and commit messages. Use `unslop` with the product copy rules for UI and landing-page text. Use `deslop` when reviewing changed code. Preserve security checks, truthful limitations, legal notices, and project behavior. Compare code with its actual target branch, not the README-only `main` branch.

These skills do not override the owner's no-test-suite policy, cloud-only execution rule, Windows x64 scope, permission boundaries, or human review requirements. The broader pstack workflow, TDD guidance, and plugin hooks are not installed.
