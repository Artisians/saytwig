# Approved visual direction

`approved-concept.png` is the compact black Saytwig concept approved by the owner
on 2026-10-29. It is **not a screenshot of the running GPUI application**; it uses
sample transcript/readiness data and an illustrative recording waveform. The
actual interface must show real states and must not animate fabricated input.

Direction: compact utility window, near-black surfaces, thin neutral separators,
quiet white/grey controls, restrained mint focus/recording accent, small overlay.
Standard controls use GPUI Kit 0.8.1 with matching gpui-pre 0.3.10 rather than an
unrelated web component kit.

Actual design guidance: official `pbakaus/impeccable`, commit
`02523aec3e4c4580102d996d1b6a71fbe062e03f` (unified skill 4.8.0). Context and
concept-seed were run, followed by quieter/distill and critique/polish guidance.
The separate remote concept-roll service was unavailable; no full remote roll
or native-app screenshot is claimed. Initial bulky navy concepts were rejected
and replaced by this owner-approved compact black direction.

The implementation also uses the pinned BeautifulRust development guidance
under `.agents/skills/`, subject to the owner's explicit no-suite policy.
